 # Personal Zellij configuraiton

This is my roaming configuration for [Zellij], a terminal multiplexer with batteries included.

## Install

### Homebrew

Using [Homebrew](https://brew.sh):

```sh
brew install zellij
```

### Cargo

To build and install the binary using `cargo`:

```sh
cargo install --locked zellij
```

### Other

See [installation](https://zellij.dev/documentation/installation.html) instructions on [Zellij] for more options.

## Set up

Clone this repo into `$XDG_CONFIG_HOME/zellij`:

```sh
git clone --depth=1 https://github.com/heaths/zellij-config ~/.config/zellij
```

[Zellij]: https://zellij.dev
